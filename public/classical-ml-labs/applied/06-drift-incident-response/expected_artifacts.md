# Expected artifacts and acceptance checks

## Files to submit

- data/synthetic.csv generated by solution.py --make-data
- artifacts/starter_metrics.json
- artifacts/solution_metrics.json
- incident_report.md with severity, owner, rollback/hold action, and revalidation plan.

## Acceptance checks

1. Running python solution.py --make-data twice produces the same CSV and metrics.
2. The metrics JSON declares a chronological 80/20 split and contains a true acceptance field.
3. The holdout utilization PSI must trigger the 0.20 drift alarm.
4. The failure-mode memo shows the invalid experiment was reset before final reporting.
5. The final memo states that this lab supports a decision, rather than replacing accountable human judgement.
