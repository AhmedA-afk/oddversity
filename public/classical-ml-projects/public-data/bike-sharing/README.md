# Bike Sharing — student-owned starter

Forecast daily rentals. The canonical source is the UCI Bike Sharing Dataset: <https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset>. Cite Fanaee-T and Gama and retain the original licence/attribution with any download.

## Data acquisition

Download the archive to git-ignored `data/raw/`, preserve its date/time indexing, and split chronologically. Do not randomly shuffle future observations into training. The tracked fixture is synthetic and only validates the offline contract.

Complete the TODOs in `starter.py`; run `python test_public.py`.
