# Online Retail — student-owned starter

Analyse customer revenue and build a transparent prioritisation baseline. The source is the UCI Online Retail dataset: <https://archive.ics.uci.edu/dataset/352/online+retail>. It describes transactional data from a UK-based retailer; preserve the required attribution and review the dataset documentation before use.

## Data acquisition

Download the UCI workbook into git-ignored `data/raw/`, retain its original filename and checksum, and document how you handle cancellations, missing customer IDs, returns, and currency assumptions. Do not claim that observed purchase value is a causal measure of marketing impact.

The small committed fixture is synthetic, deterministic, and network-free. Complete the TODOs in `starter.py`, then run `python test_public.py`.
